## 🧠 Overview
This project is a simple **Restaurant Management System** written in **8086 Assembly Language**.  
It demonstrates how to handle user input, display menu items, calculate total bills, and manage basic restaurant operations on a DOS-based system.

---

## 🎯 Objectives
- Learn and apply 8086 Assembly Language programming.  
- Build a basic restaurant management system from scratch.  
- Understand low-level logic, looping, and arithmetic operations in assembly.  
- Simulate real-world menu selection and billing logic.

---

## ⚙️ Features
✅ Display menu items with prices.  
✅ Take customer orders (item + quantity).  
✅ Calculate total bill dynamically.  
✅ Display the final payable amount.  
✅ Fully keyboard-driven (no mouse).  
✅ Works on DOS or any x86 emulator.

---

## 🧩 Technical Requirements
| Component | Specification |
|------------|---------------|
| Processor | Intel 8086 |
| Assembler | MASM / TASM / NASM |
| Operating System | DOS / DOSBox Emulator |
| Tools Used | MASM, Turbo Debugger, DOSBox |

---

## 🧮 How It Works
1. The program starts and displays a list of menu items.  
2. The user selects an item number and enters quantity.  
3. The system calculates subtotal and total bill.  
4. Final output displays ordered items and payable total.

Example:

Welcome to Mahin's Restaurant

Burger - 120

Pizza - 200

Coffee - 80

Enter item number: 1
Enter quantity: 2

Your total bill: 240
Thank you! Visit again.
