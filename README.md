# Restaurant Management System Assembly

A Restaurant Management System written in x86 Assembly Language.

## Features

- Breakfast menu
- Lunch menu
- Dinner menu
- Snacks
- Sweet items
- Drinks
- Quantity input
- Total price calculation

## How to Run

Use DOSBox with MASM or TASM.

### TASM example

```bash
tasm restaurant.asm
tlink restaurant.obj
restaurant.exe
```

### MASM example

```bash
masm restaurant.asm;
link restaurant.obj;
restaurant.exe
```
